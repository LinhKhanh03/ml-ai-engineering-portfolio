# AI Engineering Portfolio

This repository contains my personal AI Engineering portfolio, featuring projects in Generative AI, Machine Learning, Data Science, and AI Automation. The projects emphasize end-to-end development, practical problem solving, and modern AI technologies, including LLMs, Retrieval-Augmented Generation (RAG), AI agents, workflow automation, and intelligent data applications.

Each project is built to demonstrate production-oriented engineering practices, clean architecture, and the practical application of AI to real-world business scenarios.

## Projects

### RAG Document Chatbot
End-to-end RAG pipeline for PDF question answering over Vietnamese university documents.
Implements semantic chunking, multilingual BGE embeddings, MMR retrieval, Cross-Encoder reranking, and sliding window memory.
**Tech:** Python, LangChain, LangSmith, ChromaDB, Gemini API, HuggingFace, PyMuPDF

### Multi-Agent Chatbot
LangGraph-based multi-agent system with automatic tool routing across three data sources:
PDF documents, PostgreSQL (Brazilian E-Commerce/Olist dataset), and real-time web search via Tavily.
**Tech:** Python, LangGraph, LangChain, LangSmith, ChromaDB, PostgreSQL, Tavily, Gemini API, HuggingFace
